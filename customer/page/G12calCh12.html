Q:   Simplify the following expressions if possible:

Ans: အဖြေနှင့် တွက်နည်းကြည့်ရန် နှိပ်ပါ

  (i) A + AB + A\(\overline{B}\)C

  (ii) (\(\overline{A}\) + B) C + ABC

Ans:   (i) A + AB + A\(\overline{B}\)C

    = A (1 + B) + A\(\overline{B}\)C

    = A \(⋅\) 1 + A\(\overline{B}\)C   (\(\because \) 1 + B = 1)

    = A + A\(\overline{B}\)C   (\(\because \) A \(⋅\) 1 = A)

    = A (1 + \(\overline{B}\)C)

    = A \(⋅\) 1     (\(\because \) 1 + \(\overline{B}\)C = 1)

    = A     (\(\because \) A \(⋅\) 1 = A)

  (ii) (\(\overline{A}\) + B) C + ABC

    = \(\overline{A}\)C + BC + ABC

    = \(\overline{A}\)C + BC (1 + A)

    = \(\overline{A}\)C + BC \(⋅\) 1   (\(\because \) 1 + A = 1)

    = \(\overline{A}\)C + BC   (\(\because \) BC \(⋅\) 1 = BC)

    = (\(\overline{A}\) + B) C

Q:   Find the value of X for all possible values of variables.

Ans: အဖြေနှင့် တွက်နည်းကြည့်ရန် နှိပ်ပါ

  (i) X = (A + B)C + B   (ii) X = (\(\overline{A+B}\))C

  (iii) X = A\(\overline{B}\)C + AB

Ans:   (i) X = (A + B)C + B

    = AC + BC + B

    = AC + B(C + 1)

    = AC + B \(⋅\) 1   (\(\because \) C + 1 = 1)

    = AC + B     (\(\because \) B \(⋅\) 1 = B)

  (ii) X = (\(\overline{A+B}\))C ဒီမောဂင်း သီအိုရမ်သုံးရန်

    = \(\overline{A}\) \(\overline{B}\) C   (\(\because \overline{A+B}\) = \(\overline{A}\) \(\overline{B}\))

  (iii) X = A\(\overline{B}\)C + AB

    = A (\(\overline{B}\)C + B)

    = A (C + B)   (\(\because \) \(\overline{B}\)C + B = C + B)

    = AB + AB + AC + BB + BC

    = B + AC     (\(\because \) AB + B = B)
